# DATA CARD — MindPulse training datasets

Location: `backend/app/ml/artifacts/`

## `real_dataset.csv` (70 rows)

- **Source**: Kaggle "Stress Detection by Keystroke/Mouse Changes" (keystroke, mouse, application-usage data).
- **Subjects**: 2 computer users ("user 1" ×25, "user 2" ×45). No independent subjects available.
- **Labels**: 70/70 rows labeled `1` (MILD). There are NO real NEUTRAL (0) or STRESSED (2) rows.
- **Windows**: 70 derived windows; extraction details of the original pipeline are not reproducible from the repo.
- **License**: Kaggle dataset terms; verify before redistribution.

Implication: this file alone cannot support a 3-class real-world claim.

## `real_dataset_balanced.csv` (140 rows, REPAIRED Aug 2026)

Composition:

| source_type | label | count | subject |
|---|---|---|---|
| real | 1 (MILD) | 70 | user 1, user 2 |
| synthetic | 0 (NEUTRAL) | 35 | synthetic_neutral |
| synthetic | 2 (STRESSED) | 35 | synthetic_stressed |

- Synthetic rows regenerated by the **current** `synthetic_data.py` (seed 42) — reproducible.
- Non-negative features clamped ≥ 0 (0 negative values remain).
- Timestamps valid ISO-8601.
- Provenance columns: `source_type`, `source_subject`, `label_origin`, `synthetic_generator_version`.

Repair script: `backend/scripts/repair_datasets.py`. Legacy file backed up as
`real_dataset_balanced_legacy.csv` (contains the invalid dates / negative values
from the unreproducible old pipeline — kept for reference, do not train on it).

## Label validity

- Synthetic labels are **generator-defined** (label chosen first, features drawn
  from label-conditioned Gaussians). The model learns the generator's
  distributions; this is NOT independent evidence that features predict stress.
- Real labels are a single class from a 2-user public dataset. Their semantic
  validity (whether Kaggle "stress" labels equal MindPulse's 3-level scale) was
  not verified against ground truth.

## Known limitations

- 2 real subjects only → subject-independent validation infeasible on real data.
- No chronological split, no independent test set, no external validation.
- Class balance is manufactured (35/70/35), not observed.
