# MindPulse — Senior Deep Audit (Aug 13 2026)

30-minute audit, everything checked live where possible. Severity: 🔴 critical
· 🟡 warn · 🟢 nit.

## Architecture (Supabase-only)

```
Next.js (Vercel) ──supabase-js──▶ Supabase
   ├─ Auth (email/Google via provider)
   ├─ Tables (RLS): chat_*, wellness_*, focus_*, stress_history,
   │  ema_checkins, telemetry_events, user_baselines, interventions
   └─ Edge fns: infer (public model), chat (JWT-gated Gemini)
```
FastAPI backend = legacy local/dev only. Desktop client = not wired.

## Security

- 🔴 FIXED this audit: `chat_messages` RLS `using(true)` → user-scoped
  (`auth.uid() = user_id`) + migration shipped.
- 🔴 FIXED this audit: chat edge fn quota theft — `verify_jwt` alone passes
  the anon key (it IS a valid signed JWT); now signature-verified +
  `role=authenticated` enforced in-function. Verified: anon → 401.
- 🟡 FIXED: `frontend/.env.local` was committed (anon key) → untracked +
  gitignored. Stale dead-project key scrubbed from ARCHITECTURE.md.
- 🟡 Tokens `sbp_*` were pasted in chat (account-level) — revoke at
  supabase.com (2 tokens) + Kaggle token.
- 🟡 `infer` is public with anon key — model is public anyway; add
  rate-limiting if abuse observed.
- 🟢 RLS verified live: anon reads → empty, anon writes → 42501.

## Data integrity

- 🟢 stress_history insert (frontend) matches schema exactly; RLS scoped.
- 🟢 wellness upsert on_conflict(user_id, check_date) verified shape.

## API contracts (types ↔ api.ts ↔ pages ↔ edge fns)

- 🟢 34 api.ts methods match page call signatures (build enforces).

## Reliability / operations

- 🟡 No observability on edge functions (no logs dashboards, no Sentry).
  Edge fn cold start = 2MB model fetch + JSON parse (~1-2s worst case);
  poll every 5s masks it after first call.
- 🟡 Chat returns full reply (no true streaming) — client chunks for UX;
  acceptable, note in docs.
- 🟢 Tests: backend 8/8 pass after pytest.ini fix. Frontend: no test suite.
- 🟢 Vercel auto-deploy verified (build was failing earlier — 5 type
  errors found by running the exact build command; now EXIT 0).
- 🟡 Vercel env vars: NEXT_PUBLIC_SUPABASE_URL/ANON must exist in
  Production env — user confirmed set.

## Known debt (not blocking)

1. Desktop telemetry bridge targets FastAPI — needs Supabase rewrite.
2. Browser ONNX still legacy (unused — infer fn is the path).
3. No rate limit on infer; no retention on stress_history.
4. Calibration dead path (user_baselines).
5. No frontend tests.
6. Supabase Realtime not used (polling is honest at this scale).

## Verdict

🔴 Security holes from the migration are closed and verified live
(RLS + JWT authz). Data flow is real end-to-end (collector → infer →
persist → history/forecast). Remaining issues are ops debt, not
correctness — ship with the checklist: revoke tokens, retention job,
calibration wiring, observability.
